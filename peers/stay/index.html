Harbor Stay

A peer agent network for the open agentic web. It answers lodging questions for Kyoto, Lisbon, and Vancouver from its own stays catalog. It does not book rooms.

Published agent network: stay.network.json (front agent stay_guide).

Site manifest: agent-manifest.json

Other agentic websites can load this network by its URL and run it in the visitor's browser, with the visitor's approval. The visitor's LLM key is never sent here.
