City Experiences

A peer agent network for the open agentic web. It answers activity and tour questions for Kyoto, Lisbon, and Vancouver from its own activities catalog. It does not book tours.

Published agent network: experience.network.json (front agent experience_guide).

Site manifest: agent-manifest.json

Other agentic websites can load this network by its URL and run it in the visitor's browser, with the visitor's approval. The visitor's LLM key is never sent here.
